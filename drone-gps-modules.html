NAVSATE GPS Module for UAV Drones

A DroneCAN GPS module with an onboard magnetometer for UAV positioning. Compare it for flight controllers that support CAN peripherals.

NAVSATE Mini GPS Module for FPV Drones

A compact GPS module for FPV builds where mounting space is limited. It supplies position data to a compatible flight controller.

What to check before you choose

Choose the module by available space and the flight controller’s supported GPS interface. The UAV module is intended for builds that use position hold and waypoint missions. NAVSATE Mini is intended for compact FPV frames. Flight modes depend on the flight controller and its firmware.
