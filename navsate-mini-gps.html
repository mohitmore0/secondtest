NAVSATE Mini GPS Module for FPV Drones

GPS

A compact GPS module for FPV builds where mounting space is limited. It supplies position data to a compatible flight controller.

NAVSATE mini is the compact version of our UAV GPS, made for FPV builds where weight and space matter. It adds position data for features like return-to-home to racing and long-range quads.

Highlights

What to check before ordering

Ask for the current pinout, supply voltage, interface and dimensions before ordering, especially for a tight frame. Check which GPS features your flight firmware supports.
